# Online Retail Sales Analysis

## About the Project

Online Retail Sales Analysis is a data analysis project developed using Python.
The project analyzes online retail transaction data to understand sales,
products, customers, countries, and purchasing patterns.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Analysis

The project includes:

- Data loading and data exploration
- Data cleaning
- Handling missing values
- Checking data types
- Removing duplicate records
- Sales and quantity analysis
- Product analysis
- Country-wise sales analysis
- Customer and transaction analysis
- Data visualization

## Key Features

- Analyzes retail sales transactions
- Identifies sales patterns
- Analyzes product and quantity information
- Performs country-wise analysis
- Uses charts and visualizations to understand the data

## Project Purpose

The main purpose of this project is to practice data cleaning,
exploratory data analysis, and data visualization using Python.

## Tools
